# Rastaran

System POS / KDS / Zamówienia gości i kelnera dla gastronomii.

## Wymagania wstępne
- Node.js >= 24 LTS
- pnpm 11.21.x
- Docker & Docker Compose (PostgreSQL 16, Redis 7)

## Start środowiska
```bash
pnpm install
pnpm dev
```
